# Responsive HTML5 & CSS3 Website (Assignment A3)

## Project Overview
This project is a fully responsive, modern website built using HTML5 and CSS3. It is designed to adapt seamlessly across desktop, tablet, and mobile screen sizes using CSS Grid, Flexbox, and media queries.

## Key Features
- **Semantic HTML5:** Built using semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Responsive Layout:** Responsive layout powered by CSS Flexbox and CSS Grid.
- **Mobile-First Breakpoints:** Fully tailored views for Mobile (< 768px), Tablet (768px - 1024px), and Desktop (> 1024px).
- **Interactive Elements:** Responsive navigation menu, styled contact forms, and hover micro-interactions.
- **Cross-Browser Compatibility:** Standardized box-sizing and modern CSS for smooth rendering across major browsers.
